# Supersaw

Original MIT-licensed fixed-point engine: seven detuned, harmonically limited saw oscillators, a sine sub and bounded drive. It is not a port or sonic replica of OP-1 firmware; it contains no OP-1 source or tables. Fourier tables and detune ratios are generated from mathematical definitions.

Load `FMSYNTH-SUPERSAW.wav` into a FLEX slot and set VOIC to 1. `python3 modules/supersaw/marker.py out/AUDIO/FMSYNTH-SUPERSAW.wav` creates the silent selector marker. PLAYBACK: PTCH, DETU, MIX, FINE, SUB, DRIV. AMP controls the note envelope. DETU spans 0 to +/-35 cents with a quadratic response. MIX blends the centre oscillator with the six detuned sides. SUB adds a sine one octave below. DRIV adds bounded saturation; zero bypasses it. Seven oscillators form one note; per-track polyphony is not implemented and VOIC > 1 is silent.

The optional bridge composes with Sophie without changing its source. One existing Synth module owns the native hooks, while each engine recognizes its own exact marker prefix. Ordinary FM markers and effects remain selectable. No DSP code, effect ID, bus buffer or battery SRAM is allocated. With SUPERSAW absent, the previous Synth source is emitted verbatim.

`python3 modules/supersaw/generate.py` regenerates tables and assembly; `--check` checks reproducibility. The host gate checks split blocks, track independence, all controls, extreme pitches/parameters under sanitizers, exact marker boundaries, mono rejection and an independent Fourier reference. The image gate exercises FM and dual-Supersaw combinations (and requires a mixed-engine case if Sophie is also selected), both DSP cores and bus hosts, Harmony, MIDI/sequencer/Loopback release and native page labels. Hardware timing and physical audio remain unverified; emulator instruction counts are not hardware cycle measurements.

The oscillator core runs at 22.05 kHz with linear interpolation to 44.1 kHz (one output sample of latency). This lowers high-frequency brightness and provides processing headroom; the fundamental is clamped below 10.77 kHz. The resampler preserves its state across sequencer-split source calls. Implementation uses eight harmonic table banks (1..128 partials), selecting the richest bank below the internal Nyquist frequency for the highest detuned oscillator, with 2048-point nearest-sample lookup per bank. This reduces aliasing; it does not claim zero aliasing, especially after drive. Parameter changes are read per source call and are not smoothed. Long release tails, live marker changes, sustained parameter automation and hardware CPU capacity require further qualification. The existing Synth Machine's AMP/voice-switch behavior is inherited.

The POC qualification is limited to two simultaneous synth tracks: dual Supersaw or Supersaw/FM. The POC remix selects Supersaw alongside the standard modules; Sophie has a separate remix. Experimental Sophie/Supersaw playback caused excessive emulator control latency, and a three-engine Supersaw/Sophie/FM stress test starved its main task. Those combinations remain unqualified, with their failing checks retained. These are emulator results, not measured hardware voice limits; no automatic voice stealing or track cap is imposed. Derived detune and gain values are cached per voice until pitch or a control changes; controls are still read on every source call.
