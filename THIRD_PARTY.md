# Authorship and third-party material

This foundation contains original repository scaffolding for Mattias Wolff.
No third-party module source or firmware is imported at bootstrap.

The external builder is [Octabam](https://github.com/sambanks/octabam), maintained
by Sam Banks and contributors. Its module schema and author-repository integration
conventions are reused by reference; its source and toolchains remain external.

When importing existing module source, preserve the applicable licence, notices,
author attribution and source commit. Do not assume every community module uses
the same licence. This repository currently grants no general redistribution
licence; choose one before public distribution, retaining imported files' terms.

Elektron firmware is supplied by the owner locally and is not distributed here.
