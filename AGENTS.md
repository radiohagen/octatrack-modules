# Working in radiohagen/octatrack-modules

Use only the radiohagen identity for this repository. Local `git gh` invokes
its isolated CLI configuration. Do not switch global accounts or modify the
mattiaswolff repositories. Existing source attribution and persistence IDs are
not renamed merely because the hosting account changed.

Read README.md, integration/README.md and docs/UPSTREAM_PLAN.md. This repository
owns selected MIDI module source; Octabam owns schema, builder and shared tools.
Use short-lived codex/<feature> worktrees after bootstrap, and keep one coherent
change per PR. Do not add synths, ARP templates, POST FADER or unrelated effects.
Preserve source provenance. Native source paths remain until an explicitly
validated adapter migration. Never claim firmware testing from source checks.
Run make check after source/tooling changes and relevant Octabam gates after
firmware changes. Never commit firmware, samples, private device projects,
credentials or generated binary output. Keep them in ignored artifacts/out.
