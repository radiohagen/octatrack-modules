# ARP PRESETS test remix

Standalone [ARP PRESETS](../../../modules/arp-presets/README.md), with stock
audio effects. MIDI ARP SETUP uses A for a bank of 17 editable rhythms,
C for native length and F for native key/scale.

Build and verify: `make check REMIX=arp-presets`.
This is a first implementation for emulator validation; it has not been
flashed or tested on an Octatrack.
