# MIDI ensemble

Scales, Follow and Harmony with STORE, KITS, MIDI Scenes, SCENES P2, PLOCKS P2,
Part State, MIDI SRAM and the Harmony PLOCKS bridge. Audio effects stay stock.
Harmony uses MIDI TRACK retention; PLOCKS and Scenes keep separate storage.

See [MIDI ensemble controls](../../../modules/midi-harmony/README.md).
